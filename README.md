# Histórico de retrasos (EMT remake, Fase 10)

Rama de datos, sin código. Cada hora el flujo "Recogida de retrasos" añade en `data/AAAAMMDD.csv` cuánto iba tarde cada autobús frente a su viaje del horario.

Cada línea: `segundos desde medianoche (Madrid),línea,sentido,índice de parada,minutos de retraso,autobús`.

Fuente: Ayuntamiento de Málaga – datosabiertos.malaga.eu (EMT Málaga), CC BY-SA 4.0. Ver ADR 0016 en la rama main.
